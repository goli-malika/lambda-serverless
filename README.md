# AWS Lambda & Serverless Computing

## Module 05 - AWS & DevOps Internship

## What is Serverless Computing?
Serverless computing allows developers to build and run applications without managing the underlying server infrastructure.

## Key Features
- No server management
- Automatic scaling
- Event-driven execution
- Usage-based pricing
- Faster development

## Real-World Applications
- Image processing
- Email notifications
- Order processing
- File management
- Serverless APIs

## AWS Services
- AWS Lambda
- Amazon API Gateway
- Amazon S3
- Amazon DynamoDB

Understand the fundamentals of serverless computing and AWS Lambda.
