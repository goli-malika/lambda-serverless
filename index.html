Student Information – Serverless API

Welcome to my AWS & DevOps Internship project! This project demonstrates a simple serverless API using Python and AWS concepts.

About the Project

A Student Information API that demonstrates how GET and POST requests are handled using a Python Lambda-style function.

Technologies Used

Python AWS Lambda API Gateway JSON

API Endpoints

GET /students

Retrieves student information.

Status Code: 200

POST /students

Accepts student information and returns a success response.

Status Code: 201

Serverless Architecture

Client
↓
API Gateway
↓
AWS Lambda
↓
JSON Response

Project Result

Successfully tested GET and POST request handling locally using Python.
